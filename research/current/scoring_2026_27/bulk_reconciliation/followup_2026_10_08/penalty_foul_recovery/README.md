# Converted penalty foul pilot — withheld

A frozen pilot links a direct penalty goal to a unique ordinary foul-won / foul-
committed pair, mirrored position, explicit penalty-taker reference and no
intervening play. It distinguishes a fouled taker (no self-assist) from a different
foul winner, and excludes handball. Details and minimum control sizes were frozen
in `protocol.json` before outcome comparison.

Only six applicable 2025/26 one-goal controls were found, all for a different foul
winner; none disagreed. This is below the 20-control overall gate and provides no
self-won control coverage. **No kind is qualified and no fields are applied.**
Do not lower the gate or call previously inspected outcomes an independent holdout.
Future work needs additional suitable temporal goal-level evidence or a separately
frozen, justified validation design with honest limits, not another copy of this
same six-control comparison.
