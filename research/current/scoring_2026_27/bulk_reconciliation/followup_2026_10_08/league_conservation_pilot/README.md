# Competition-total source pilot — unavailable

The new hypothesis was that an explicit league-season line-clearance total could
bound the five teams whose season totals are omitted. One season-scoped
`stats/comp/1?compSeasons=274&altIds=true` schema probe returned HTTP 404.
No totals were recovered, no batch was attempted, and no values were derived.
A future attempt requires a documented supported aggregate endpoint or a different
source; do not repeat guessed endpoint permutations or interpret 404 as zero.
