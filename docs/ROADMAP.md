## Gode første bidrag

- Kontroller én rapport mot lagrede resultatfiler og dokumenter hva som kan gjenskapes.
- Prøv oppsettet på en ny maskin og rapporter konkret manglende input eller avhengighet.
- Gjennomgå én avgrenset PR og foreslå tydeligere resultatforklaring.

Ikke gjenta forkastede varianter uendret. Ikke sammenlign gamle og omregnede poeng som én resultatliste. Den prospektive perioden skal ikke brukes til å velge nye regler.
